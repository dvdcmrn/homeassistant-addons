# Icons

Optional reference SVGs versioned alongside the Cupertino Icons integration. The integration loads icons from `www/cupertino-icons/` on your Home Assistant config, not from this directory.

No Apple SF Symbols artwork is shipped in this repository.

| File | Notes |
| --- | --- |
| `playstation.logo.svg` | Reference asset from legacy **pinnacles** (not an SF Symbol). Review trademark use before dashboards. |

Export SF Symbols on a Mac with **File → Export Image…** (SVG), or use `scripts/export_sf_symbols.py` (AppleScript helper). Validate exports with `scripts/validate_sf_icons.py`.
