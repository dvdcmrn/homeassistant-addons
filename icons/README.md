# Icons

This folder is for **optional reference SVGs** you may want to version alongside the Cupertino Icons integration. The integration itself loads icons from `www/cupertino-icons/` on your Home Assistant config, not from this directory.

No Apple SF Symbols artwork is shipped in this repository.

Legacy files from the archived `pinnacles` repository (`playstation.logo.svg`, `export_sf_symbols.py`) were not imported automatically (private repository was not accessible to the consolidation environment). Use `scripts/validate_sf_icons.py` for export validation; add reference SVGs here if useful.
